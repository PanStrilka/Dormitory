# 🧽 Bulka — správa buňky (менеджер гуртожитської буньки)

Веб-застосунок для організації **прибирання, чергувань і спільних витрат** у
блоковій системі гуртожитку: **дві кімнати по 4 людини + спільна буньк­а**
(кухня, ванна, WC) — разом 8 мешканців.

Створено під конкретний гуртожиток у **Дечині (ЧР)** на основі офіційного
документа *«ZÁSADY – provádění samoúklidu v pokojích ubytovacího zařízení»*
(денні / тижневі / місячні обов'язки). Інтерфейс — **чеською та англійською**
(перемикач одним кліком).

> Застосунок повністю статичний: нічого не треба встановлювати, працює на
> будь-якому телефоні через браузер і хоститься **безкоштовно** (GitHub Pages).

## Що вміє

| Розділ | Що робить |
|--------|-----------|
| **Dnes / Today** | Показує, чия зараз черга по кожній із 4 ролей, і чек-лист завдань саме на цей тиждень (денні + тижневі, а в «місячний» тиждень ще й місячні). Відмічаєш зроблене → рахуються бали. |
| **Rozpis / Rota** | Повний розклад чергувань на будь-який тиждень (вперед/назад) + графік «Vyváženість служеб» — скільки разів кожен відчергував. |
| **Výdaje / Expenses** | Спільні витрати у стилі Splitwise: хто купив мило/папір/рушники — тому винні решта. Застосунок сам рахує «хто кому і скільки» найкоротшими переказами. |
| **Body / Points** | Бали, рівні (Бронза → Платина) і «жетони імунітету» як мотивація. |
| **Nastavení / Settings** | Мешканці, дата старту, валюта, мова, синхронізація, експорт/імпорт. |

### Логіка чергувань (справедлива й автоматична)

- **4 ролі щотижня:** `Кімната 1`, `Кімната 2` (назви редагуються), `Кухня + кіш`, `Ванна + WC`.
- Кожна кімната по черзі прибирає **свою** кімнату; **спільну буньку** чергують усі 8 по колу.
- **Ніхто не відповідає за все відразу:** спільні чергування дістаються лише тим, хто цього тижня **не** черговий по своїй кімнаті. (Перевірено: за повний цикл навантаження в усіх **однакове**, і немає жодного тижня з подвійним чергуванням.)
- Розклад **детермінований** — рахується з дати старту, тому на всіх телефонах він однаковий навіть без сервера.
- **Місячний глибокий прибір** автоматично додається в тиждень, на який припадає 1-ше число місяця.

### Передача чергування (коли когось немає)

Кнопка 🔄 біля будь-якої ролі → обираєш, хто підміняє, і за бажанням лишаєш
нотатку (напр. «pryč 12.–20. 9.»). Бали за виконання отримує той, хто реально
прибирав.

### Бали й привілеї (мотивація)

- Виконане завдання = бали: **денне 1, тижневе 4, місячне 8**.
- За кожні **50 балів** — **жетон імунітету** (можна пропустити одне дрібне завдання).
- Рівні: 🥉 Бронза (0) · 🥈 Срібло (50) · 🏆 Золото (120) · 💎 Платина (250).

## Як запустити

### Варіант А — просто відкрити (для проби)
Завантаж репозиторій і відкрий `index.html` подвійним кліком. Працює одразу,
дані зберігаються **в цьому браузері** (localStorage).

### Варіант Б — опублікувати безкоштовно на GitHub Pages (рекомендовано)
У репозиторії вже є GitHub Actions workflow (`.github/workflows/deploy.yml`),
який публікує сайт при кожному пуші. Потрібен **один разовий клік** від власника
репозиторію (GitHub не дозволяє це зробити автоматично з міркувань безпеки):

1. **Settings → Pages → Build and deployment → Source: `GitHub Actions`** (обрати й зберегти).
2. Все — тепер кожен пуш у `main` чи робочу гілку деплоїть сайт (вкладка **Actions**).
   Перший деплой можна запустити вручну: **Actions → Deploy to GitHub Pages → Run workflow**.
3. Готовий сайт з'явиться за адресою
   `https://panstrilka.github.io/Dormitory/` — кидай посилання всім сусідам.

## Синхронізація між усіма 8 телефонами (безкоштовно, за бажанням)

За замовчуванням дані живуть у кожному браузері окремо. Щоб **усі бачили одне
й те саме наживо**, увімкни синхронізацію через безкоштовний **Supabase**:

1. Створи безкоштовний проєкт на <https://supabase.com> (план Free вистачає).
2. У проєкті відкрий **SQL Editor** і виконай:

   ```sql
   create table if not exists bulka_state (
     id text primary key,
     data jsonb,
     updated_at timestamptz default now()
   );
   -- Дозволяємо доступ анонімним ключем (дані невразливі — лише побутове).
   alter table bulka_state enable row level security;
   create policy "bulka read"  on bulka_state for select using (true);
   create policy "bulka write" on bulka_state for insert with check (true);
   create policy "bulka update" on bulka_state for update using (true);
   ```

3. У **Project Settings → API** скопіюй **Project URL** та **anon public key**.
4. У застосунку: **Nastavení → Data a synchronizace** — встав URL і ключ,
   натисни **Uložit a synchronizovat**. Зелена крапка вгорі = синхронізація активна.
5. Дай ті самі URL+ключ решті сусідів (або просто поділись, і кожен вставить їх
   один раз). Зміни підтягуються протягом кількох секунд.

> Синхронізація навмисно проста (спільний JSON, «останній запис перемагає») —
> цього більш ніж достатньо для квартири на 8 людей. Без Supabase застосунок
> працює так само, лише локально.

### Резервна копія без Supabase
**Nastavení → Exportovat data** зберігає всі дані у файл `bulka-data.json`;
**Importovat data** відновлює їх (або переносить на інший телефон).

## Структура проєкту

```
index.html        # каркас сторінки, підключення скриптів
styles.css        # оформлення (світла + темна тема, мобільний-first)
js/
  duties.js       # каталог обов'язків з документа (CZ + EN)
  i18n.js         # переклади інтерфейсу (чеська / англійська)
  store.js        # стан застосунку, збереження, робота з ISO-тижнями
  rotation.js     # рушій справедливого чергування + передача чергувань
  points.js       # бали, рівні, жетони імунітету
  expenses.js     # спільні витрати (Splitwise-стиль)
  sync.js         # опційна синхронізація через Supabase
  ui.js           # рендер усіх вкладок і взаємодія
  app.js          # запуск
```

Жодних зовнішніх бібліотек чи складання — чистий HTML/CSS/JS.

## Налаштування під себе

- **Мешканці:** *Nastavení → Spolubydlící* — додай 8 імен і признач кімнату (Кімната 1 / Кімната 2).
- **Назви кімнат:** *Nastavení → Názvy pokojů* — назви як завгодно (напр. номери «201», «202»).
- **Навчалка:** при першому відкритті показуються підказки; знову — кнопкою **❔** вгорі.
- **Верифікація:** *Nastavení → Přístup a ověření* — задай **код буньки**. Нові
  мешканці натискають «Připojit se», вводять імʼя й код → потрапляють у
  «Žádosti o připojení», де ти їх **схвалюєш**. Лише схвалені входять у чергування.
- **Встановити на телефон:** відкрий сайт у браузері → меню → «Додати на
  екран Домівки». Застосунок стане повноекранним і працюватиме офлайн (PWA).
- **Дата старту чергувань:** *Nastavení → Začátek rozpisu* (з неї рахується вся ротація).
- **Валюта:** за замовчуванням `CZK`.
- **«Хто я»:** вгорі справа обери своє ім'я — тоді підсвічується «твоя черга» і твої привілеї.
